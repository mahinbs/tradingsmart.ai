# Public assets

Place your static assets here. They are served from the site root.

**Required files:**

| File | Used in |
|------|--------|
| `logo.png` | Header, footer, admin layout, admin login |
| `ai_stock_hero_bg.webp` | Hero background on AI Stock Prediction page |

After adding these files, the logo and hero background will show correctly in the app and on deployment.
